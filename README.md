# Digital--Clock
A simple, modern, and responsive Digital Clock built with HTML, CSS, and JavaScript. The clock displays the current time in real-time with a clean and minimal interface.
✨ Features
🕐 Real-time clock updates
📅 Displays current date
🎨 Clean and responsive UI
⚡ Lightweight and fast
📱 Works across desktop and mobile devices
🔄 Automatically updates every second
